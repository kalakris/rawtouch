The first release of RawTouch: trackpad-style scrolling on macOS for the
trackpads built into a ZMK keyboard. The keyboard sends the finger's
position through the [`zmk-raw-touch`](https://github.com/kalakris/zmk-raw-touch)
firmware module, and RawTouch turns it into phased scroll gestures, the
kind a Mac trackpad produces: content follows the finger, coasts after a
flick, and stops when the finger touches down again. Without the app,
the keyboard keeps pointing and wheel-scrolling by itself.

## Install

1. Flash firmware built with `zmk-raw-touch` 0.1. Go60 owners: the
   [Go60 configuration](https://github.com/kalakris/go60-rawtouch-config)
   has prebuilt firmware, and steps for building it with your own
   keymap, including one made in MoErgo's Layout Editor.
   Other keyboards need a ZMK 0.3 / Zephyr 3.5 tree; ZMK `main` is not
   supported yet. After flashing, Bluetooth hosts must forget the
   keyboard and pair again, with the bond cleared on the keyboard too.
2. Download `RawTouch-v0.1.0.dmg` below, move `RawTouch.app` into
   **Applications**, and open it.
3. In the setup window, click **Grant Access…**. When macOS asks, choose
   **Open System Settings**, then switch RawTouch on under **Privacy &
   Security → Accessibility**. RawTouch needs Accessibility to post
   scroll events.

The [README](https://github.com/kalakris/rawtouch#readme) covers each step,
and how to verify the download's signature and build provenance.

## What is in it

- Vertical and horizontal scrolling with gesture phases, lift-off momentum
  and touch-to-stop, timed to the display's refresh.
- Settings for gain, acceleration, momentum and per-pad direction, written
  to `~/.config/rawtouch/config.json` (the file can be edited by hand and
  reloads live).
- One set of settings per keyboard, whether it is connected over USB,
  Bluetooth or both.
- A menu bar status line per keyboard (RawTouch mode or Standard mode), and
  the firmware version each half of a split reports, in
  **Settings → Keyboards**.
- A notify-only update check: once a day, and from **Check for Updates…**
  in the menu, RawTouch asks GitHub's API for the latest release of the
  app and of the firmware module, sending only the app version, and lists
  anything newer in its menu. It never downloads anything. **Check for
  updates automatically** in **Settings → Advanced** turns the daily
  check off.

## Compatibility

- macOS 13 or later, Apple silicon and Intel (a universal binary).
- Firmware: `zmk-raw-touch` 0.1.x, protocol 4.
- Tested on a MoErgo Go60 with two Cirque Pinnacle pads, on Apple silicon
  running macOS 26, over USB and Bluetooth.

## Known limitations

- One finger per pad, and one pad scrolls at a time.
- Not yet tested: macOS 13 to 15, Intel Macs, keyboards other than the
  Go60, and two RawTouch keyboards used at once. Reports are welcome.
